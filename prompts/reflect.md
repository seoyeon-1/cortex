## REFLECTION ON FAILURE
If the previous patch failed:
1. Did the patch apply cleanly? (Check tool result summary).
2. Did the tests pass? If not, read the NEW error trace carefully.
3. Was the hypothesis wrong? (e.g., fixed wrong function, wrong variable name).
4. Did I break something else? (Regressions).
5. Formulate a NEW hypothesis and try a DIFFERENT fix.
